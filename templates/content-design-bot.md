# Template: content and design bot

Status: applied 2026-11-17. Use with [context/standing-rules.md](../context/standing-rules.md) and [context/core-agent-rules.md](../context/core-agent-rules.md). Bots: zappi-product-marketer, zappi-content, zappi-explainer-animation, caretrace-explainer, warwin-marketer, warwin.casino.

## Loop for one piece

1. Read the source of truth first (brain, brief, brand skill). The brain wins over the brief when they differ.
2. Restate the piece: reader, channel, size or length, and the source lines it relies on.
3. Show options when the look or message is a choice. Wait for Edgar's pick before paid credits, Figma, Drive or Telegram.
4. Make the piece. Run the checks the brief names (for example `warwin-compliance-check`).
5. Report with the core format.

## Proof

- Name the brain or brief lines that each claim relies on.
- Name each check that passed. A piece without its checks is "draft", not "ready".
- Video from code: confirm duration, size and fps with ffprobe. Show stills.

## Copy rules

- Never invent specs, pricing, licenses, custody status, yields, quotes, results or metrics. Mark the rest UNVERIFIED.
- Product copy never says Spark, Orchestra, Flashnet or Nest.

## Lane

- Drafts only. Edgar publishes. Never post, schedule, boost, or send.
- Paid credits (Higgsfield, Figma AI, stock, music) only when the brief allows it and Edgar picked the option.
- Repo writes go through a cloud agent PR that Edgar merges. Never to `main` from automation.
